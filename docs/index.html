LinTux

Seus comandos do terminal, com nome curto.

Salve comandos longos uma única vez, encadeie-os em listas de execução e rode tudo com lintux <nome>. O LinTux mostra o que vai executar, pede confirmação antes de operações perigosas e guarda backup dos seus dados.

Instalar Repositório no GitHub ↗
git clone https://github.com/miqueiasklippel/lintux.git && cd lintux && ./install.sh

experimente

Um terminal simulado, que responde como o LinTux. Digite um comando ou toque nos exemplos abaixo. Nada é executado no seu computador.

tux@linux: ~ — bash simulação
Experimente:

Dicas: Tab completa nomes, ↑ e ↓ navegam no histórico, e clear limpa a tela.

o que ele faz

Um único arquivo Python, que usa só a biblioteca padrão. Útil para quem está começando no Linux e para quem quer trocar aliases espalhados por algo organizado.

Comandos salvos

Guarde qualquer comando, com pipes, redirecionamentos e &&, sob um nome curto.

lintux add atualizar 'sudo apt update && sudo apt upgrade -y' lintux atualizar

Listas de execução

Etapas em ordem, com progresso. A lista para na primeira falha e diz onde foi.

[1/3] Executando: atualizar... ✔ Etapa 1/3 concluída (2,4 s).

Parâmetros

Transforme um comando em modelo. Os argumentos são sempre escapados antes de ir ao shell.

lintux add porta 'ss -tulpn | grep {{1}}' lintux porta 8080

Veja antes de executar

Inspecione o código guardado ou simule a execução completa de uma lista.

lintux show manutencao lintux -n manutencao

Rede de proteção

Pede confirmação antes de rm -rf /, mkfs, dd, curl | sh e desligamentos.

⚠ Atenção: operação potencialmente destrutiva detectada

Backup e histórico

Backup com um comando na pasta Downloads, restauração por mesclagem e registro de cada execução.

lintux new backup lintux history

instalação

Funciona em Debian, Ubuntu, Linux Mint, RHEL, Fedora, CentOS, AlmaLinux, Rocky Linux e derivados. Escolha a sua família de distribuições.

  1. Instale os requisitos

    O Python 3 já vem na maioria das distribuições desktop. O comando abaixo garante o Python e o Git.

    sudo apt install python3 git
    sudo dnf install python3 git

  2. Baixe o projeto

    Clone o repositório oficial e entre na pasta.

    git clone https://github.com/miqueiasklippel/lintux.gitcd lintux

  3. Execute o instalador

    Instala para todo o sistema em /usr/local/bin e pede a senha do sudo. Para instalar só para o seu usuário, sem sudo, use ./install.sh --user.

    ./install.sh

  4. Teste

    Abra um novo terminal, para ativar o autocompletar com a tecla Tab, e salve o seu primeiro comando.

    lintux add ola 'echo "Olá, $USER!"'lintux olalintux help

Sem Git?

Baixe o arquivo ZIP do projeto ↗ e, na pasta onde ele foi salvo:

unzip lintux-main.zip && cd lintux-mainbash install.sh

Atualizar ou remover

Rodar o instalador de novo atualiza a versão sem tocar nos seus dados. Para remover, use o desinstalador, que pergunta se deve apagar ~/.lintux.

./uninstall.sh# --keep mantém os dados; --purge apaga após um backup final

referência rápida

Os comandos mais usados. O guia completo aparece com lintux help.

ComandoO que faz
Executar
lintux <nome> [args]Executa um comando ou uma lista
lintux -n <nome>Simula: mostra o que seria executado, sem executar
lintux -k <lista>Continua as próximas etapas mesmo se uma falhar
lintux -y <nome>Dispensa a confirmação de operações perigosas
Comandos
lintux add <nome> '<comando>'Salva um novo comando
lintux edit <nome> ['<novo>']Altera o código (sem texto, abre o editor)
lintux rm <nome>Remove o comando e o retira das listas
lintux show <nome>Mostra o código sem executar
Listas
lintux add list <lista>Cria uma lista vazia
lintux add list <lista> <comando>Adiciona um comando já salvo como etapa
lintux add list <lista> <novo> '<código>'Salva um novo comando e já o adiciona à lista
lintux mv <lista> <de> <para>Move uma etapa de posição
lintux rm list <lista> [etapa]Remove a lista ou uma etapa; os comandos continuam salvos
Organizar
lintux list [cmd | lists]Mostra comandos e listas
lintux search <termo>Procura em nomes, códigos e descrições
lintux rename <atual> <novo>Renomeia e atualiza as listas que o usam
lintux historyMostra as últimas execuções
Backup
lintux new backup [pasta]Cria um backup (padrão: pasta Downloads)
lintux add backup <arquivo>Restaura e mescla um backup aos dados atuais

⚠ Use aspas simples ao salvar comandos

Operadores como &&, |, > e ; são lidos pelo seu shell antes de chegarem ao LinTux. Sem aspas, só a primeira parte é salva e o resto é executado na hora.

✔ lintux add atualizar 'sudo apt update && sudo apt upgrade -y'
✖ lintux add atualizar sudo apt update && sudo apt upgrade -y

Se o comando já tiver aspas simples por dentro, use aspas duplas por fora: "echo 'olá'". Na demonstração acima você pode testar os dois jeitos.
